# 💻 C Programming

A collection of C programs and exercises documenting my progress from programming fundamentals to pointers, algorithms, and data structures.

This repository is organized into stages, with each section focusing on a different part of the C programming language.

## 🗺️ Learning Path

### ✅ 01 — C Fundamentals
Core concepts and fundamentals of C programming.

- Hello World
- Variables and Data Types
- If-Else Statements
- Loops
- Functions
- Arrays
- Strings
- Structs and Unions
- Bitwise Operators

### 🔄 02 — Pointers and Memory
Working directly with memory and understanding one of the most important concepts in C.

- Pointers
- Swap with Pointers
- Pointer Arithmetic
- Strings with Pointers
- Dynamic Arrays
- Dynamic Memory Allocation
- `malloc()` and `free()`
- Combining pointers with structs and other C concepts

### ⏳ 03 — Algorithms in C
Implementing fundamental algorithms from scratch using C.

- Recursion
- Searching Algorithms
- Sorting Algorithms

### ⏳ 04 — Data Structures in C
Building fundamental data structures using pointers and dynamic memory.

- Linked Lists
- Stacks
- Queues

## 🧠 What This Repository Demonstrates

Throughout this repository, I practice:

- Writing structured C programs
- Problem solving with C
- Working with functions and modular code
- Understanding pointers and memory
- Managing dynamic memory
- Implementing algorithms from scratch
- Building fundamental data structures
- Combining previously learned concepts in more advanced examples
