# 🧠 Algorithms in C

This section contains implementations and exercises focused on fundamental algorithms in C.

The examples are organized into recursion, searching algorithms, and sorting algorithms.

## 📂 Structure

### 🔁 Recursion

Programs focused on understanding recursive functions, base cases, and recursive problem solving.

#### Human Pyramid

Calculates the weight supported by a person in a human pyramid.

The problem is solved using both recursive and iterative approaches, allowing the two methods to be compared.

**Concepts practiced:**
- Recursion
- Base cases
- Multiple recursive calls
- Recursive problem decomposition
- Iterative problem solving
- 2D arrays

#### Recursive Factorial

Calculates the factorial of a number recursively.

**Concepts practiced:**
- Basic recursion
- Base cases
- Returning recursive expressions

#### Recursive Fibonacci

Calculates a Fibonacci number using recursion.

**Concepts practiced:**
- Multiple recursive calls
- Base cases
- Recursive mathematical sequences

#### Recursive Practice

A custom recursive exercise using different conditions to determine how the next recursive call is made.

**Concepts practiced:**
- Multiple base cases
- Conditional recursion
- Recursive expressions
- Breaking a problem into smaller subproblems

---

### 🔎 Searching Algorithms

Programs focused on finding elements efficiently within data structures.

#### Binary Search

Searches for a value in an array using the Binary Search algorithm.

The array is sorted before the search begins. The search repeatedly reduces the search range by comparing the target value with the middle element.

**Concepts practiced:**
- Binary Search
- Sorted arrays
- Search boundaries
- Middle index calculation
- Returning search results

---

### 📊 Sorting Algorithms

Programs focused on arranging array elements in ascending order using different approaches.

#### Bubble Sort

Sorts an array by repeatedly comparing adjacent elements and swapping them when they are in the wrong order.

**Concepts practiced:**
- Bubble Sort
- Nested loops
- Adjacent element comparison
- Swapping values

#### Insertion Sort

Implements the standard Insertion Sort algorithm.

Each element is inserted into its correct position within the already sorted portion of the array.

**Concepts practiced:**
- Insertion Sort
- Sorted and unsorted portions
- Shifting array elements
- Using a key value

#### Array Sorter

A sorting exercise that moves elements backward through the array using comparisons and swaps.

**Concepts practiced:**
- Array traversal
- Nested loops
- Swapping values
- Passing arrays to functions
- Pointer-based array parameters
