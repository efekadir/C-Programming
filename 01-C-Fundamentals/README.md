## C Fundamentals

This section contains my exercises and small programs covering the fundamental concepts of the C programming language.

It represents the first stage of my C programming journey, from basic syntax to bitwise operations.

## 📚 Topics

### 01 — Hello World
Basic C program structure, console output, and simple operations.

### 02 — Variables and Data Types
Variables, primitive data types, constants, type conversions, and user input.

### 03 — If-Else
Conditional statements and decision-making using `if`, `else if`, and `else`.

### 04 — Loops
Repetitive operations using `for`, `while`, and `do-while` loops.

### 05 — Functions
Function declarations, parameters, return values, and basic modular programming.

### 06 — Arrays
Working with one-dimensional and multi-dimensional arrays.

### 07 — Strings
String manipulation, character arrays, and common string operations.

### 08 — Structs and Unions
Creating custom data structures using `struct` and understanding shared memory with `union`.

### 09 — Bitwise Operators
Binary-level operations using bitwise AND, OR, XOR, NOT, and bit shifting.
